# Changelog

## v1.0.0 (2026-07-05)

Initial release of the Rust Developer Pack with 12 expert-level skills:

- **Rust-Expert** — Core language mastery: ownership, lifetimes, generics, traits, error handling, macros, unsafe, FFI
- **Cargo-Expert** — Build system mastery: workspaces, features, profiles, cross-compilation, sccache
- **Tokio-Expert** — Async runtime mastery: tasks, channels, I/O, timers, structured concurrency, tracing
- **Axum-Expert** — Web framework mastery: extractors, middleware, state, WebSockets, OpenAPI
- **Bevy-Expert** — Game engine mastery: ECS, rendering, UI, assets, plugins, Bevy 0.14+
- **Serde-Expert** — Serialization mastery: derive macros, custom ser/de, formats, zero-copy
- **SQLx-Expert** — Database mastery: compile-time queries, migrations, pools, transactions, multi-DB
- **Clap-CLI-Expert** — CLI mastery: derive API, subcommands, completions, validation
- **Rust-Testing-Expert** — Testing mastery: unit/integration, mocking, property-based, fuzzing, coverage
- **Rust-Benchmarking** — Performance mastery: Criterion, profiling, flamegraphs, dhat
- **Unsafe-Rust-Review** — Safety mastery: raw pointers, FFI, Miri, soundness verification
- **Rust-Memory-Optimization** — Memory mastery: layout, allocators, arenas, cache efficiency

Each skill includes: SKILL.md, references.md, examples.md, templates.md, checklists.md, snippets.md.
