### 4. FFmpeg-Creator-Expert

### 5. ImageMagick-Expert

### 9. YouTube-SEO-Expert

## Installation

1. Ensure you have an AI assistant platform that supports skill packs (such as OpenCode or compatible CLI tools).
2. Clone or download the skill pack repository to your local machine.
3. Copy the `Creator-Tools-Pack` folder into your skill packs directory.
4. Load the desired skill using your AI tool's skill loading mechanism.
5. Refer to each skill's `SKILL.md` for detailed activation instructions.

### Requirements

- AI assistant platform with skill pack support
- File system access to skill pack directory
- Individual skill software installed (Blender, DaVinci Resolve, OBS Studio, FFmpeg, ImageMagick, Aseprite, Krita, Audacity) for full utility
