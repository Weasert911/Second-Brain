## Template 2: Thumbnail Design Blueprint

**Description:** Design specifications for high-CTR thumbnails.

```
Name: Thumbnail_{{video_topic}}

Canvas: 1280 x 720 pixels
Format: PNG (preferred) or JPEG (high quality 95%)

Elements:
1. Background: {{bg_color}} or {{bg_image}}
   - High contrast with text and subject
   - Solid background or blurred scene

2. Subject: {{subject_type}}
   - Face close-up: {{expression}} (surprised, excited, curious, angry)
   - Product/object: {{object_name}} with {{object_position}}
   - Composition: rule of thirds, subject on left/right

3. Text (max 5 words):
   - Font: {{font_name}} (bold, sans-serif)
   - Color: {{text_color}} with {{stroke_color}} stroke
   - Size: 72-120pt (readable at 50px width)
   - Position: {{text_position}} (bottom, left of subject)
   - Content: {{text_content}} (big promise, question, curiosity gap)

4. Accents:
   - Arrows: {{arrow}} pointing to key element
   - Icons: {{icon}} for visual shorthand
   - Borders: {{border_style}} (to frame or emphasize)

5. Branding:
   - Logo: {{logo_position}} (corner, consistent across channel)
   - Color palette: {{brand_colors}} (2-3 consistent colors)

Test: View at 50px width — is the key message readable?
```

**Usage Notes:** A/B test 2-3 thumbnail variants using YouTube Test & Compare. Highest CTR wins. Keep text minimal — viewers should understand the video in <2 seconds.

## Template 3: Video Structure Script

**Description:** Script structure optimized for retention.

```
Name: Video_{{topic}}_{{duration}}

Total Target Duration: {{target_duration}} minutes

1. Hook (0:00 – 0:15)
   - Start with most interesting moment
   - Promise value: "In this video, you'll learn {{value_promise}}"
   - Pattern interrupt (visual or audio change)

2. Introduction (0:15 – 1:00)
   - Context: "This is important because {{reason}}"
   - Preview: "First I'll cover {{point_a}}, then {{point_b}}"
   - Subscribe CTA: "Subscribe for more {{content_type}}"

3. Main Content Sections (1:00 – {{end_minus_cta}})
   - Section 1: {{topic_1}} ({{duration_1}} min)
   - Section 2: {{topic_2}} ({{duration_2}} min)
   - Section 3: {{topic_3}} ({{duration_3}} min)
   - Section 4: {{topic_4}} ({{duration_4}} min)
   - Section 5: {{topic_5}} ({{duration_5}} min)

4. Pattern Interrupts (every 2-3 minutes)
   - Visual change: B-roll, animation, text overlay
   - Audio change: sound effect, music change
   - Question to audience

5. Call to Action ({{cta_timestamp}} – {{end}})
   - Summary: "So to recap, {{key_takeaways}}"
   - Like CTA: "If this helped, hit the like button"
   - Comment CTA: "What's your experience with {{topic}}?"
   - Subscribe CTA: "Subscribe for more {{content_type}}"
   - Next video: "Check out {{next_video_title}}"

6. End Screen (last 20 seconds)
   - Visible subscribe button
   - Recommended video thumbnail
   - Playlist link (if series)
```

**Usage Notes:** Keep hook under 15 seconds. Pattern interrupt every 2-3 minutes. CTA should feel natural, not rushed. Keep outro under 20 seconds.

## Template 7: End Screen and Card Strategy

**Description:** End screen and card placement strategy.

```
Name: EndScreen_{{video_topic}}

End Screen Elements (last 20 seconds):
1. Subscribe: Bottom-left, {{subscribe_prompt}}
2. Video: Most clicked recommendation / Best for viewer
3. Playlist: Link to {{playlist_name}} (if series)

Card Placements:
| Timestamp | Card Type | Content | Goal |
|-----------|-----------|---------|------|
| {{time_1}} | Video | {{video_1}} | Related topic crosslink |
| {{time_2}} | Video | {{video_2}} | Series continuation |
| {{time_3}} | Channel | {{channel}} | Collaboration cross-promo |
| {{time_4}} | Playlist | {{playlist}} | Binge-watching session time |

Best Practices:
- First card before 3-minute mark
- Distribute cards evenly throughout video
- Don't overlay cards on critical visual content
- Use "Best for viewer" for end screen video recommendation
- Match card content to current video topic
```

**Usage Notes:** First card at 1-2 minutes. Last card before end screen. Total 2-4 cards per video. End screen video should have high retention to maximize session time.
