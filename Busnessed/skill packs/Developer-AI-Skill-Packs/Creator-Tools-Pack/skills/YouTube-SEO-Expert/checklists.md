# YouTube-SEO-Expert Checklists

## Pre-Flight Checklist

- [ ] Keyword research completed for target topic
- [ ] Top 3 competitor videos analyzed for structure
- [ ] Title drafted with primary keyword front-loaded
- [ ] Title under 60 characters
- [ ] Thumbnail designed with high contrast and focal point
- [ ] Thumbnail readable at 50px width
- [ ] Video script written with retention-focused structure
- [ ] Hook planned for first 15 seconds
- [ ] Chapters mapped out with timestamps
- [ ] CTA planned (subscribe, like, comment)

## Implementation Checklist

- [ ] Title contains primary keyword in first 40 characters
- [ ] Description starts with keyword-focused paragraph (200 chars)
- [ ] Timestamps added for all chapters
- [ ] 3-5 relevant hashtags in description
- [ ] Tags section filled with 10-15 keywords
- [ ] End screen configured with subscribe + video recommendation
- [ ] Cards added at strategic timestamps
- [ ] Video thumbnail uploaded before publishing
- [ ] Playlist selected or created for video
- [ ] Community post drafted for after publish

## Testing Checklist

- [ ] Preview video plays without errors
- [ ] Thumbnail displays correctly in YouTube Studio
- [ ] End screen elements are positioned properly
- [ ] Cards are visible and link to correct videos
- [ ] Chapters match video content correctly
- [ ] Description links work (verify URLs)
- [ ] Tags are indexed (check in incognito)
- [ ] Video visibility set correctly (public/unlisted/private)
- [ ] Monetization status confirmed (if applicable)
- [ ] Copyright check shows no issues

## Release Checklist

- [ ] Video published at optimal time for audience
- [ ] Community post published announcing video
- [ ] Video shared on other social platforms
- [ ] Notifications enabled for subscribers
- [ ] First 1 hour: monitor comments and respond
- [ ] First 24 hours: track CTR and retention
- [ ] End screen promoted video has high retention
- [ ] Cards point to best-performing content
- [ ] Description updated with any missed links
- [ ] Analytics snapshotted for future comparison

## Maintenance Checklist

- [ ] Monthly keyword research for new opportunities
- [ ] Analytics reviewed weekly for first month of each video
- [ ] Underperforming videos re-optimized (title, thumbnail, description)
- [ ] Playlists updated with new content
- [ ] Old video descriptions refreshed with new chapter standards
- [ ] Competitor analysis updated quarterly
- [ ] End screen templates reviewed and updated
- [ ] Community tab engagement tracked and optimized
