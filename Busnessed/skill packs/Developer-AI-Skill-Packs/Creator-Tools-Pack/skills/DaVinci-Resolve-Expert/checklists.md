# DaVinci-Resolve-Expert Checklists

## Pre-Flight Checklist

- [ ] Project settings match final delivery specifications
- [ ] Color management policy configured before importing media
- [ ] Media organized into bins with consistent naming
- [ ] Timeline frame rate matches source footage
- [ ] Proxy or optimized media generated for smooth playback
- [ ] Auto-save and project backups enabled
- [ ] Database backup exists for collaborative projects
- [ ] Reference monitor calibrated and warmed up
- [ ] Audio interface selected and configured
- [ ] Licensed software for all required codecs confirmed

## Implementation Checklist

- [ ] Rough cut assembled from script or storyboard
- [ ] Fine-cut with J-cuts and L-cuts applied for pacing
- [ ] Transitions and effects placed with consistent timing
- [ ] Primary color grade balances exposure and white balance
- [ ] Secondary grades isolate and correct specific areas
- [ ] Skin tones verified on vectorscope
- [ ] Fusion composites checked for edge artifacts
- [ ] Titles and graphics are high resolution and readable
- [ ] Fairlight tracks routed to appropriate buses
- [ ] Dialogue, music, and SFX levels balanced

## Testing Checklist

- [ ] Timeline plays in real-time without stuttering
- [ ] Color grade holds across scene transitions
- [ ] Fusion effects render without cracking or flickering
- [ ] Audio levels meet -14 LUFS (web) or -23 LUFS (broadcast)
- [ ] No clipping on master bus
- [ ] Titles appear at correct duration and position
- [ ] Export at full resolution matches source quality
- [ ] Multi-cam angles switch correctly
- [ ] Speed changes and retiming play smoothly
- [ ] Closed captions or subtitles synced to audio

## Release Checklist

- [ ] Final export rendered at highest quality setting
- [ ] Secondary exports for web/social generated
- [ ] Project archived with all media and PowerGrades
- [ ] LUTs and looks saved externally for reuse
- [ ] Render files verified by spot-checking frames
- [ ] Audio mix checked on multiple playback systems
- [ ] Color grade reviewed on calibrated reference monitor
- [ ] Project notes and metadata saved
- [ ] Backup database exported to external storage
- [ ] Delivery checklist signed off by team

## Maintenance Checklist

- [ ] Resolve version updates checked monthly
- [ ] Database optimized and backed up weekly
- [ ] Cache and render files cleaned periodically
- [ ] PowerGrade library organized and deduplicated
- [ ] LUT library updated with new versions
- [ ] Plugin and script compatibility verified
- [ ] Keyboard shortcuts and workspace exported
- [ ] Media archive storage checked for integrity
