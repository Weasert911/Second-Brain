# OBS-Expert Checklists

## Pre-Flight Checklist

- [ ] OBS updated to latest stable version
- [ ] Graphics drivers updated
- [ ] Upload bandwidth tested (fast.com or speedtest.net)
- [ ] Scene collection created and organized
- [ ] All sources tested and visible in preview
- [ ] Audio levels checked — mic not clipping, desktop audio audible
- [ ] Audio filters applied and tested
- [ ] Encoder settings configured for target platform
- [ ] Stream key entered and verified as active
- [ ] Hotkeys assigned without conflicts

## Implementation Checklist

- [ ] Starting soon scene with countdown or static image
- [ ] Main content scene with game capture and webcam
- [ ] BRB scene with appropriate message
- [ ] Ending scene with social links and thanks
- [ ] Browser source for alerts configured and tested
- [ ] Chat overlay or capture configured
- [ ] Stinger or transition selected and tested
- [ ] Multi-track audio track mapping configured
- [ ] Recording settings configured for local archive
- [ ] Replay buffer enabled (if desired)

## Testing Checklist

- [ ] Stream preview looks clean with correct aspect ratio
- [ ] Audio levels hit -6dB to -12dB on meter
- [ ] Mic filters remove background noise without distorting voice
- [ ] Game capture runs at full FPS without capture lag
- [ ] Webcam image is properly lit and framed
- [ ] Browser sources load and update correctly
- [ ] Scene transitions play smoothly without stutter
- [ ] Hotkeys trigger correct actions
- [ ] Test recording plays back without issues
- [ ] OBS log shows no errors or warnings after test

## Release Checklist

- [ ] Final stream key verified
- [ ] Stream title and description set on platform
- [ ] Category/game selected correctly
- [ ] Tags and metadata added
- [ ] Moderation tools active (if applicable)
- [ ] Backup streamer/co-host briefed
- [ ] Stream health visible (FPS, dropped frames, CPU usage)
- [ ] Recording storage has sufficient space
- [ ] Emergency scene (technical difficulties) ready
- [ ] Post-stream backup of logs and recordings planned

## Maintenance Checklist

- [ ] OBS updated monthly
- [ ] Plugins updated to compatible versions
- [ ] Scene collections backed up to cloud storage
- [ ] Logs reviewed periodically for performance trends
- [ ] Audio filters re-tested after driver updates
- [ ] Overlay URLs checked for service changes
- [ ] Hotkeys reviewed for conflicts with new software
- [ ] Recording storage cleaned and archived
