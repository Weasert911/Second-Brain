# Thumbnail-Workflow-Expert Checklists

## Pre-Flight Checklist

- [ ] Video content reviewed for key visual moment
- [ ] Frame captured or screenshot taken at highest quality
- [ ] Thumbnail dimensions set to 1280x720
- [ ] Color mode sRGB for web display
- [ ] Brand color palette selected
- [ ] Font chosen (bold sans-serif, legible at small size)
- [ ] Reference inspiration collected (competitor analysis)
- [ ] Template selected (if series)
- [ ] A/B test variants planned (if testing)
- [ ] Tool ready (Photoshop/GIMP/Canva/Figma)

## Implementation Checklist

- [ ] Subject clearly visible and emotionally engaging
- [ ] Face close-up with recognizable expression
- [ ] Background removed or stylized for contrast
- [ ] Color grading applied (slight saturation boost)
- [ ] Text added (max 5 words, bold, with stroke/shadow)
- [ ] Text does not overlap face
- [ ] Branding element (logo) positioned consistently
- [ ] Episode/series badge added (if applicable)
- [ ] Image sharpened for clarity
- [ ] Dimensions verified (1280x720)

## Testing Checklist

- [ ] Thumbnail viewed at 50px width — text readable?
- [ ] Thumbnail viewed at 50px width — subject identifiable?
- [ ] Test on mobile device at arm's length
- [ ] Check in YouTube Studio preview (dark and light mode)
- [ ] Compare with competitor thumbnails (does it stand out?)
- [ ] File size under 2MB
- [ ] Export quality acceptable (no artifacts)
- [ ] Variants substantially different (for A/B testing)
- [ ] A/B test set up in YouTube Studio (if available)
- [ ] Thumbnail accurately represents video content

## Release Checklist

- [ ] Thumbnail uploaded to YouTube Studio
- [ ] Custom thumbnail selected (not auto-generated)
- [ ] A/B test started (if applicable)
- [ ] Thumbnail verified on published video
- [ ] Check on mobile YouTube app
- [ ] Check on desktop YouTube
- [ ] Share to social media with thumbnail visible
- [ ] Monitor CTR in first 48 hours
- [ ] Replace underperforming thumbnails <3% CTR
- [ ] Log thumbnail performance data for future reference

## Maintenance Checklist

- [ ] Monthly review of thumbnail CTR data
- [ ] Top-performing thumbnail patterns identified
- [ ] Template updated based on performance insights
- [ ] Brand assets reviewed for consistency
- [ ] Font licenses checked (if commercial fonts used)
- [ ] Color palette refreshed seasonally (if appropriate)
- [ ] Competitor thumbnail trends analyzed quarterly
- [ ] Old underperforming thumbnails replaced
