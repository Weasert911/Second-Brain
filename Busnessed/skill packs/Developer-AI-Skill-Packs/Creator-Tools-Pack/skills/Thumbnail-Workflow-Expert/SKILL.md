- Maintain branding consistency: logo placement, palette, font family across thumbnails
- Execute creation workflow across tools (Photoshop, GIMP, Canva, Figma, Photopea)
- Perform A/B thumbnail testing using YouTube Test & Compare
- Apply platform-specific guidelines: YouTube 1280x720, light/dark mode readability
- Implement face close-up best practices for emotional connection
- Apply text overlay do's and don'ts for maximum readability

## Required Tools

- Image editor: Photoshop, GIMP, Canva, Figma, or Photopea

- Color palette generator (Adobe Color, Coolors)

## Execution Workflow

1. Review video content to identify key visual moment for thumbnail
2. Capture or select high-quality frame from video
3. Determine composition: subject placement, background, focal point
4. Choose color scheme based on brand guidelines and content mood
5. Select and place subject with emotional expression (face close-up)
6. Add text overlay (3-5 words maximum) if needed
7. Apply color grading/effects to match brand style
8. Add branding elements (logo, consistent badge)
9. Export at 1280x720 (YouTube standard) at maximum quality
10. Upload to YouTube Studio as custom thumbnail
11. Upload 2-3 variants for A/B testing if available
12. Analyze CTR after 2 weeks and iterate on design

## Decision Tree

- Content type → {Tutorial, Entertainment, Review, Vlog, Gaming, Educational}
- Thumbnail style → {Face close-up, Text heavy, Before/after, Minimalist, Bold graphic}
- Color strategy → {Brand colors, Complementary, Monochromatic, Warm/cool contrast}
- Text needed → {Yes (3-5 words), No (image only), Minimal (1-2 words)}
- Subject focus → {Face/expression, Product, Action shot, Scene, Composite}
- Branding level → {Minimal (logo only), Moderate (style consistent), Strong (template-based)}
- Platform → {YouTube (1280x720), TikTok/Reels (vertical), Twitter (16:9), Custom}
- Quantity → {Single, Series (consistent template), Batch (same template, varied content)}

## Review Checklist

- [ ] Thumbnail is 1280x720 pixels (YouTube standard)
- [ ] Key subject is clearly visible and recognizable
- [ ] Face close-up has emotional expression
- [ ] Text readable at 50px width (mobile thumbnail size)
- [ ] Text uses bold, sans-serif font with stroke/shadow
- [ ] Maximum 5 words in text overlay
- [ ] High contrast between subject and background
- [ ] Colors are vibrant and saturated (not muted)
- [ ] Brand colors and logo are consistent
- [ ] File format is PNG or high-quality JPG/JPEG
- [ ] Thumbnail matches video content (no clickbait)
- [ ] Variants available for A/B testing

## Troubleshooting

| Problem | Cause | Solution |
|---|---|---|
| Low CTR (<4%) | Thumbnail not compelling | Increase contrast, add face with emotion, larger text |
| Thumbnail blurry at small size | Low resolution source | Export at 1280x720 minimum, avoid small text |
| Text unreadable on mobile | Font too small or thin | Use bold fonts, minimum 24pt, add stroke |
| Colors look dull on YouTube | Compression desaturating | Increase saturation 10-15% over normal |
| Face looks unnatural | Poor expression selection | Choose candid emotion, not forced smile |
| Text hard to read on background | Low contrast | Add text shadow, stroke, or semi-transparent bg |
| Thumbnail too busy | Too many elements | Remove 50% of elements, focus on single subject |
| Branding inconsistent across videos | No template | Create and use branded template for all thumbnails |
| A/B test shows no winner | Variants too similar | Make variants substantially different |
| Client rejects design | Taste mismatch | Present 3 options: safe, creative, bold |

## Best Practices

- Use face close-ups with clear emotion (surprise, excitement, curiosity)
- Keep text to maximum 5 words, bold sans-serif font
- Use complementary colors for visual pop
- Ensure subject fills at least 30% of thumbnail frame
- Add drop shadow or stroke to text for readability
- Use high contrast between elements
- Test on mobile before publishing (view at 50px width)
- Maintain consistent color palette across channel
- Include branding element (logo) in consistent position
- Create template for series to speed production

## Anti-Patterns

- Using text in ALL CAPS (feels like shouting)
- Placing text over faces
- Using too many colors (3 maximum)
- Making thumbnails that don't match video content (clickbait)
- Using low-resolution images that pixelate on large screens
- Overusing arrows, circles, and "click me" indicators
- Placing text at bottom (cut off in YouTube suggested videos)
- Using thin, decorative fonts (unreadable at small size)
- Designing without considering light/dark mode on YouTube
- Reusing same thumbnail design for every video without variation
