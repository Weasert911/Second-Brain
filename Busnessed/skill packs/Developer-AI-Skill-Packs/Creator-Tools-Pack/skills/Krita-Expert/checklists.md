# Krita-Expert Checklists

## Pre-Flight Checklist

- [ ] Canvas resolution and DPI match output requirements
- [ ] Color profile selected for target medium (sRGB/CMYK/AdobeRGB)
- [ ] Graphics tablet calibrated and tested
- [ ] Krita updated to latest stable version
- [ ] Custom brushes and resources loaded
- [ ] Auto-save configured with 5-minute interval
- [ ] Memory limit configured for large canvases
- [ ] Reference images imported and organized
- [ ] Assistant tools created for perspective work
- [ ] Timeline settings configured for animation

## Implementation Checklist

- [ ] Sketch layer created for initial composition
- [ ] Line art refined with appropriate brush and stabilizer
- [ ] Flat colors applied on separate layers beneath line art
- [ ] Shading layers added with multiply/screen blend modes
- [ ] Highlights and reflections included for depth
- [ ] Texture applied with specialized brushes
- [ ] Filter layers used for nondestructive adjustments
- [ ] Color palette consistent across entire piece
- [ ] Layer groups organized with descriptive names
- [ ] Blend modes used correctly for intended effects

## Testing Checklist

- [ ] Zoom to 100% to check overall composition
- [ ] Colors viewed on calibrated monitor
- [ ] Print output proofed (color, resolution, bleed)
- [ ] Brush strokes display correct pressure response
- [ ] Animation plays at correct frame rate without skipping
- [ ] Layer visibility toggles confirm correct stacking
- [ ] Filter layers produce expected effect
- [ ] Mask boundaries are clean and accurate
- [ ] PSD export opens correctly in target software
- [ ] File size manageable for intended use

## Release Checklist

- [ ] Final .kra file saved and backed up
- [ ] Export in required formats (PNG, TIFF, PSD, JPEG)
- [ ] Layer names follow naming conventions
- [ ] Unused layers and groups removed
- [ ] Color profile embedded in exported files
- [ ] Animation rendered to video file (if applicable)
- [ ] Brush presets saved for project-specific needs
- [ ] Resources bundled for team sharing
- [ ] Copyright metadata added to output
- [ ] Delivery package organized with all required files

## Maintenance Checklist

- [ ] Krita version checked for updates monthly
- [ ] Resource bundles organized and deduplicated
- [ ] Brush presets reviewed and cleaned
- [ ] Color profiles updated to latest standards
- [ ] Memory and performance settings optimized
- [ ] Custom scripts tested after version updates
- [ ] Backup of preferences and resources maintained
- [ ] Tablet driver updated and recalibrated as needed
