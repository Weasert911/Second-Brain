# Krita-Expert Examples

## Beginner Example: Simple Digital Painting

**Goal:** Paint a simple landscape with basic brushes.

**Steps:**
1. New file: 1920x1080, 300 DPI, sRGB color profile
2. Fill background with light blue for sky
3. Use wet brush for sky gradient (white to blue)
4. Block in green hills using round brush with opacity pressure
5. Use tree brush for distant tree silhouettes
6. Add cloud shapes with soft airbrush
7. Apply color balance filter layer for warm sunset tone
8. Export as PNG for web

**Key Techniques:** Basic brush selection, layer blocking, filter layers, soft brush blending.

## Intermediate Example: Character Illustration with Colorize Mask

**Goal:** Create a clean line art character with flat colors using colorize mask.

**Steps:**
1. Sketch layer: rough character pose with pencil brush
2. Ink layer: clean line art with ink brush and stabilizer (value: 20)
3. Create colorize mask layer above line art
4. Use fill tool (colorize) to block in base colors for skin, hair, clothes
5. Refine colorize mask edges with smaller brush
6. Add shading layer (multiply) on top with soft airbrush
7. Add highlight layer (screen) for specular on hair and eyes
8. Add overlay layer for texture and atmosphere
9. Group all color layers under "Color" group, set blend mode to normal

**Key Techniques:** Colorize mask workflow, stabilizer for clean lines, multiply/screen shading, layer groups.

## Advanced Example: Frame-by-Frame Animation with Lip-Sync

**Goal:** Create a 24-frame character animation with lip-sync for dialogue.

**Steps:**
1. Animation workspace: 24 FPS, 640x480, transparent background
2. Create character rig layers: body, head, eyes, mouth
3. On mouth layer, draw 8 mouth shapes for phonemes
4. Add audio track (import WAV file) for dialogue reference
5. Enable onion skin: 2 previous frames, 1 next frame
6. Animate body bounce with subtle movement across frames
7. Animate eyes: blink every 12 frames, occasional glance
8. Lip-sync mouth shapes to audio phonemes
9. Add in-between frames for smooth transitions
10. Export as video (H.264) or GIF sequence
11. Add sound layer for final playback

**Key Techniques:** Layer-based character rigging, phoneme mouth chart, onion skin animation, audio sync, video export.

## Production Example: Concept Art with 3D Integration

**Goal:** Produce professional concept art using Krita's 3D model reference and custom brushes.

**Steps:**
1. Import 3D model reference (OBJ format) via File > Import > 3D Model
2. Position camera angle for desired composition
3. Create paint layer above 3D reference, reduce reference opacity to 30%
4. Use sketch brush to block in composition over 3D reference
5. Create custom brush: rough texture tip for environment, smooth for organic
6. Paint base colors and values using airbrush
7. Use perspective assistants for architectural elements
8. Add detail passes with textured brushes for surface quality
9. Apply filter layers: curves for contrast, color balance for mood
10. Add haze overlay layer for depth atmosphere
11. Export as PSD for delivery to client
12. Archive .kra file with all layers intact

**Key Techniques:** 3D model reference integration, custom brush creation, perspective assistants, filter layer color grading, PSD export for collaboration.
