# 🌐 Web Developer AI Skills

Build production-ready web applications faster. React, Next.js, Node, Docker, databases, authentication — 12 AI skills for modern full-stack development.

## Skills Included

### 1. React-Expert
Build dynamic user interfaces with React 18/19. Covers hooks, context API, suspense, concurrent features, server components, React Router, state management (Redux, Zustand, Jotai), performance optimization, testing with React Testing Library, error boundaries, portals, and forms with react-hook-form.

### 2. Nextjs-Expert
Full-stack React framework expertise covering App Router vs Pages Router, Server Components, route groups, parallel routes, intercepting routes, layout system, loading/error/not-found boundaries, data fetching patterns, ISR/SSG/SSR, middleware, edge runtime, image and font optimization, SEO with metadata API, auth integration, API route handlers, rewrites/redirects, and i18n.

### 3. Tailwind-CSS-Expert
Utility-first CSS mastery including responsive breakpoints, custom theme configuration, arbitrary values, variants, dark mode strategies, animations and keyframes, component extraction with @apply, plugin development, design system integration, JIT mode, production optimization, CSS layers, container queries, and Tailwind CSS v4 features.

### 4. Nodejs-Expert
Server-side JavaScript expertise covering event loop phases, streams, buffers, worker threads, cluster mode, async patterns, error handling, file system operations, package management, ESM vs CJS, module resolution, process management, environment variables, and debugging.

### 5. Express-Expert
Web framework expertise covering application vs router middleware, error handling, route parameters, request validation (Joi, Zod), file upload (multer), rate limiting, security headers (helmet), CORS, compression, template engines (Pug, EJS), async error handling, testing with supertest, API versioning, HTTPS, and WebSocket integration.

### 6. REST-API-Design
Design elegant and scalable REST APIs covering resource-oriented design, HTTP methods semantics, status codes, pagination, filtering/sorting, HATEOAS, API versioning, OpenAPI/Swagger documentation, JWT/API key authentication, rate limiting, caching (ETag, Last-Modified), error format consistency, and idempotency.

### 7. GraphQL-Expert
GraphQL API development covering schema definition language, resolvers hierarchy, N+1 problem with DataLoader, mutations, subscriptions, federation (Apollo Federation), code-first vs SDL-first, Relay patterns, custom scalars, directives, error handling, caching, and security (depth limiting, cost analysis, auth directives).

### 8. PostgreSQL-Expert
Relational database expertise covering schema design, indexing (B-tree, GiST, GIN, BRIN), query planning with EXPLAIN ANALYZE, CTEs, window functions, full-text search, JSON/JSONB operations, transactions, locking, partitioning, replication, connection pooling (PgBouncer), migrations, backup/restore, and monitoring.

### 9. Prisma-Expert
Modern ORM expertise covering Prisma schema modeling, migrations, Prisma Client CRUD operations, relations, raw queries, middleware/interceptors, transactions, batch operations, logging, error handling, connection management, performance optimization, Studio usage, seeding, and deployment.

### 10. Supabase-Expert
Open-source Firebase alternative covering project setup, PostgreSQL schema design, Row Level Security policies, real-time subscriptions, authentication, storage buckets, edge functions (Deno), database functions and triggers, migrations, client SDK, local development with CLI, and production best practices.

### 11. Docker-for-Web-Apps
Containerization for web applications covering Dockerfile best practices, multi-stage builds, docker-compose for full-stack apps, networking, volumes, environment management, health checks, logging drivers, resource limits, secrets management, BuildKit, CI/CD integration, and orchestration basics.

### 12. Authentication-Systems
Complete authentication covering JWT (structure, signing, verification, refresh rotation), OAuth2 flows, OIDC, session-based auth, MFA/2FA (TOTP), password hashing (bcrypt, argon2), CSRF protection, rate limiting for auth endpoints, social login integration, RBAC, token storage best practices, and passwordless auth (magic links, WebAuthn).
