## Installation

1. Clone or download this pack into your opencode skills directory:
   ```
   git clone https://github.com/your-org/cli-and-devops-pack.git
   ```
2. Configure opencode to load the pack by adding to `opencode.json`:
   ```json
   {
     "skills": [
       "path/to/CLI-And-DevOps-Pack/skills/*"
     ]
   }
   ```
3. Restart opencode and activate the desired skill for your task.

## Compatibility

- **Platforms**: Windows, macOS, Linux
- **Requirements**: opencode v1.0+, Git 2.x, GitHub CLI (for PR/Actions skills), Docker (for container skills), FFmpeg (for multimedia skill), CMake 3.x (for build skills)
- **Shell**: PowerShell 5.1+ / bash 4+
