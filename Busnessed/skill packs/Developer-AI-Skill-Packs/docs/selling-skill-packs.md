## License for Customers

The MIT license allows customers to:
- Use skills for any project, commercial or personal
- Modify and customize skills
- Include in their team's workflows
- Distribute within their organization

What customers cannot do:
- Resell the skills as standalone products
- Include in competing products without modification

## Distribution

Deliver as `.zip` files with a clear README and installation guide.
