## Structure

Each skill contains:
- **SKILL.md** — Main instruction file (metadata, workflow, decision trees)
- **references.md** — Official docs, terminology, conventions, architecture
- **examples.md** — Beginner to production-quality examples
- **templates.md** — Reusable project templates
- **checklists.md** — Pre-flight, implementation, testing, release checklists
- **snippets.md** — Curated reusable code snippets
- **assets/** — Template files (.gd, .tsx, .rs, .sh, .blend, etc.)
