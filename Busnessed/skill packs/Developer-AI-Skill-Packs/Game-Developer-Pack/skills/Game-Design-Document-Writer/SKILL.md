## Capabilities
- Structure complete game design documents with all sections
- Document core gameplay loops and meta loops
- Design detailed game mechanics with parameters
- Create progression systems and player growth curves
- Build economy balancing spreadsheets and formulas
- Write narrative design documents with branching paths
- Create level design documentation with flowcharts
- Design monetization strategies (F2P, premium, hybrid)
- Document accessibility requirements
- Write technical design documents
- Plan QA testing strategies

## Limitations
- Does not cover Godot engine implementation (see Godot 4 Expert)
- Does not cover specific genre game design
- Does not cover legal or business planning
- Does not replace player testing and iteration

## Required Tools
- Document editor (Google Docs, Notion, Obsidian)
- Spreadsheet software (Excel, Google Sheets)
- Diagramming tool (Miro, draw.io, Figma)
- Version control for documents (Git)

## Execution Workflow
1. Define game concept and unique selling points
2. Document core gameplay loop
3. Design and detail all game mechanics
4. Create progression and reward systems
5. Balance economy with formulas and spreadsheets
6. Write narrative outline and character profiles
7. Design levels with blockout documentation
8. Plan monetization and retention strategy
9. Document technical requirements
10. Create QA and testing plan
11. Review and iterate based on feedback

## GDD Structure
- Executive Summary
- Core Gameplay Loop
- Mechanics & Systems
- Progression & Economy
- Narrative & Characters
- Level Design
- Art & Audio Direction
- Technical Design
- Monetization
- Accessibility
- QA & Testing
- Post-Launch Plan
