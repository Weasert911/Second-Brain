# Game Design Document Writer - Checklists

## GDD Review Checklist

### Executive Summary
- [ ] Elevator pitch clear and compelling
- [ ] Genre, platform, target audience defined
- [ ] Unique selling points identified (3-5)
- [ ] Comparable games listed

### Core Gameplay Loop
- [ ] Primary loop diagram complete
- [ ] Secondary/metagame loops defined
- [ ] Player motivation cycle described
- [ ] Loop duration per iteration estimated
- [ ] Engagement drivers identified

### Mechanics
- [ ] All core mechanics documented
- [ ] Input/Output clearly specified
- [ ] Formulas and parameters detailed
- [ ] Edge cases considered
- [ ] Failure states documented
- [ ] Balance parameters justified

### Progression
- [ ] Level curve formula defined
- [ ] XP and reward table calculated
- [ ] Skill trees or ability unlocks designed
- [ ] Difficulty curve mapped to progression
- [ ] Milestones and pacing established

### Economy
- [ ] All currency types defined
- [ ] Earning rates calculated
- [ ] Spending sinks identified
- [ ] Balance targets set
- [ ] Monetization strategy (if F2P)

### Narrative
- [ ] Story synopsis complete
- [ ] Character profiles for main cast
- [ ] Dialogue system documented
- [ ] Branching narrative maps (if applicable)
- [ ] Lore and worldbuilding consistent

### Level Design
- [ ] Level flow diagrams complete
- [ ] Difficulty curve per level
- [ ] Enemy and encounter placements
- [ ] Collectible and secret placements
- [ ] Visual landmarks designed

### Art Direction
- [ ] Art style reference images included
- [ ] Color palette defined
- [ ] Character design guidelines documented
- [ ] Environment style guide created
- [ ] UI/UX mockups included

### Audio
- [ ] Music style and direction defined
- [ ] Sound effect categories listed
- [ ] Voice acting requirements (if any)
- [ ] Audio middleware requirements

### Technical
- [ ] Engine and tools selected
- [ ] Minimum system requirements listed
- [ ] Recommended system requirements listed
- [ ] Performance targets documented
- [ ] Multiplayer architecture (if applicable)

### Monetization
- [ ] Business model clearly stated
- [ ] IAP catalog defined (if F2P)
- [ ] Pricing strategy documented
- [ ] Consumer psychology considered

### Accessibility
- [ ] Colorblind mode planned
- [ ] Control remapping supported
- [ ] Subtitle options available
- [ ] Difficulty options provided
- [ ] Screen shake toggle available

### QA & Testing
- [ ] Test plan written
- [ ] Bug tracking tool selected
- [ ] Beta testing strategy defined
- [ ] Performance benchmarks set
- [ ] Launch criteria established

### Post-Launch
- [ ] Content roadmap for first 6 months
- [ ] Patch cycle frequency defined
- [ ] Community management plan
- [ ] Live ops strategy (if applicable)
