## Capabilities
- Integrate Steamworks SDK with Godot via GDNative/GDExtension
- Implement Steam achievements and stat tracking
- Configure Steam leaderboards
- Set up Steam Cloud save synchronization
- Manage DRM considerations and Steam CEG
- Optimize Steam store page with capsule art
- Configure build depots and branch management
- Manage Early Access workflow
- Implement update delivery via Steam
- Set up community features (forums, screenshots, workshop)
- Configure pricing and regional settings

## Limitations
- Does not cover Godot engine fundamentals (see Godot 4 Expert)
- Does not cover non-Steam distribution platforms
- Does not cover console or mobile store submission
- Does not cover game-specific marketing strategy

## Required Tools
- Steamworks SDK
- Steamworks developer account ($100 fee)
- Godot Steam integration plugin (GodotSteam or GDNative)
- Image editor for capsule art
- Video editing for store trailer

## Execution Workflow
1. Create Steamworks app entry
2. Configure app admin settings
3. Integrate Steamworks SDK into Godot
4. Set up achievements and leaderboards
5. Implement Steam Cloud saves
6. Create store page content
7. Prepare capsule art in all required sizes
8. Configure depots and build branches
9. Upload first build
10. Set up store visibility and pricing
11. Launch and monitor

## Store Page Requirements
- Capsule art (small, large, main, hero)
- Screenshots (minimum 5)
- Trailer/video
- Short description
- Long description
- System requirements
- Tags and categories
